| Folder | What it is | Can you touch it? |
| --- | --- | --- |
| .git | Git's database — your entire version history. | Never edit. |
| .github | CI recipe — typecheck + desktop installers on every push. | Edit when changing builds. |
| .zcode | Local AI-tooling session data (leftover plans). Untracked. | Safe to delete. |
| .freebuff | External dev-tool state. Untracked from git (R52). | Safe to delete. |
| dist | Compiled output of npm run build. Regenerable, safe to delete. | Regenerable. |
| docs | ARCHITECTURE.md — the authoritative architecture record. ROUND-*.md are per-round build reports. verify/ holds the bundle baseline. | Read/reference. |
| node_modules | Installed npm dependencies. | Regenerable (npm install). |
| public | Static assets served as-is: the vendored Python runtime (pyodide/) and fonts (fonts/). | Keep — this is your offline capability. |
| scripts | round16/17 gauntlets (verification), audit-architecture.ts + smoke.ts (R52 gates), toolchain/icon/WASM helpers. | Run via npm run verify / audit:arch. |
| server | The Node side: dev server, reality folder API, disk daemon. Desktop replaces it natively. | Source — editable. |
| src | The app itself: React UI, the 3D engine, physics, realities, encrypted vault, everything you see on screen. | Source — editable. |
| src-tauri | The desktop shell: Rust commands, app config, icons — and where the C++ core gets compiled into the binary. | Source — editable. |
