## 2. EFFICIENT — Physics memoization (debt #12 from the debt register)

**File:** `src/physics/physicsEngine.ts`.

Of the 41 fields `calculatePhysics` derives, only ~8 change with sim time. The render
loop used to recompute **all 41 per body per frame** just to read a constant
`eccentricity` (multiple call sites: main system, inner systems, orbit-line builders).

Now: the full solve runs **once per body** (keyed by an orbit/radius/kind signature);
every later call mutates only the live orbital-state fields (anomaly → Kepler solver →
distance → velocity → force/potential/flux). First call per body = full solve; every
frame after ≈ free.

- **Verified live:** memo object reused across calls; `currentDistanceAU` advances with
  sim time (0.667 → 0.680 → 0.701) and returns exactly to its start (deterministic);
  mass/eccentricity stay constant.
- Habitable-status greenhouse bumps (aurelia +33K, veil +450K) stay in the frozen solve —
  they are id-constant.

## 3. ADVANCE — Server hardening + debris sweep

**`server/index.ts`:** the reality disk-mirror API (create/rename/**delete** folders) was
listening on `0.0.0.0` with no auth — any LAN device could erase the source tree
(the deferred "Round 2 — Network" item from the 2026-09-22 audit).

- Now binds **`127.0.0.1` by default**; LAN exposure requires an explicit `HOST=0.0.0.0`
  env opt-in, and the boot log says so when you do.
- **Verified live:** restarted server now shows `TCP 127.0.0.1:3000 LISTENING`.

**Debris:** `dump-solprime.tmp.ts` (root-level dev dump) deleted.
