# Round 13 — True Glass Command Deck (2026-09-24)

## Addendum — The Core Sigil, a real instrument (R35)

The header's glowing dot was a CSS gradient pretending to be an orb — the same
"generated" tell the glass wave attacked. Replaced with **`CoreSigil.tsx`**, a
live-rendered Three.js precision instrument in a 54px viewport:

- **Chronograph chapter ring** — 60 machined bezel ticks; every 5th longer and
  brighter (minute-register convention); the active tick **steps forward once
  per second with an eased escapement snap**, like a mechanical movement.
- **Three gimbal rings** on distinct true axes (precessing, never repeating),
  each carrying four register dots like machined gimbal holes.
- **Geodesic wire cage** (subdivided icosahedron) over a breathing plasma core
  with a restrained halo, plus **one orbiting satellite** laying a fading trail
  behind it (`setDrawRange` so the trail grows from the core, never origin).
- **Tab-accent retint**: a `MutationObserver` on the plate's `data-accent`
  re-tints every material live when the active tab changes (verified:
  cyan `34 211 238` → gold `242 193 120`).
- Full GPU hygiene: devicePixelRatio-sharp, complete disposal on unmount,
  reduced-motion respected via the plate's existing mercy rules.

**Bug caught by live verification:** the satellite trail buffer was allocated
`Float32Array(90)` for 90 *points* (needs 270 floats) — a `RangeError` froze
the render loop on a garbage white frame. Fixed with a `TRAIL_PTS * 3`
allocation, right-aligned writes, and `setDrawRange`. Zero exceptions since.

The old `.core-sigil` CSS orb is now unused; the instrument is the header.

## Addendum 2 — The Forge Seal & the honest tooltip (R36)

The Forge button's thought cloud was the last fake in the header, and the
screenshot exposed a bug the design hid: the **native browser tooltip floated
on top of the designed cloud** (double tooltip). Rebuilt the shared
`ThinkingCloudTooltip` (all three usages benefit — deck, HUD bar, drawer):

- **The Forge Seal** — the gradient-blob button became a precision SVG
  instrument: 48 graduated outer-ring dashes (every 6th a register mark), a
  counter-rotating reticle ring with four register dots, a beveled forge-plus
  glyph, and an ignition spark that brightens on hover. Rings spin slow at
  rest, accelerate on approach; `currentColor` inherits the cyan; glass seat
  per the Round-13 law; reduced-motion respected.
- **Native `title` removed** — the designed cloud *is* the tooltip; no more
  double-tooltip flicker.
- **The cloud is true glass** — `abyss/60` + `backdrop-blur-2xl saturate-150`,
  light-caught hairlines, matching the deck's language.
- **Edge-aware placement** — the seal sits near the deck's right edge, so the
  centered cloud clipped its own subtitle (caught in the screenshot). The
  cloud now measures the seal at hover and anchors to the near edge, puffs
  following; verified: cloud right edge 1220px inside the 1440px window.

> "That rectangular box with dark blue color — it obviously gives the vibe it
> is made from AI. Make it transparent and glassy so it gives a premium vibe."

This wave replaces the deck's opaque navy slabs with **real glass**: the living
cosmos bends through every pane. BUILD: **R34**.

## The diagnosis

The Multiverse Core Command Deck's surfaces painted solid dark-navy
(`rgba(13,21,38,0.66)` cards, `bg-slate-900/60` columns, `bg-black/30`
footers, and the main plate at 68–84% opacity). Flat opaque fills are exactly
the "generated dashboard" tell. A full-screen animated starfield
(`CoreBackdrop`) and the actual 3D universe sat right behind the deck —
smothered by paint.

## The change — light instead of paint

**Foundation (`src/index.css`):**
- `.core-plate` — navy at 68–84% → **true glass**: 40–56% translucency +
  `backdrop-filter: blur(22px) saturate(1.35)`. The matrix rim beams, aurora
  pools and hairline insets stay; the cosmos now glows through.
- `.cc-panel` — navy gradient → **white frost** (`rgba(255,255,255,0.075→0.03)`)
  with `blur(16px) saturate(1.4)`, a light-caught top hairline and dark under-
  lip (real glass has both). Accent appears on approach, never painted at rest.
- `.cc-vital`, `.cc-btn-glass` — same frost recipe; hover keeps the gold-white
  luxury signature.
- New `.cc-glass-card` utility — shared frosted pane for sub-surfaces.
- `.cc-radar-frame` — glowing grid over frosted glass (no nested backdrop blur;
  it lives inside an already-blurred panel — GPU budget stays for the deck).

**Component sweep (every opaque slab, not just the mentioned ones):**
- `BentoRealityCard` — the anchored card's navy gradient overlay replaced with
  the shared glass; telemetry pods, galaxy chips, action footer glassified.
- `DeepHierarchyExplorer` — both columns → `.cc-glass-card`; system cards frost.
- `QuantumBinTab` — stat tiles, audit stream, bin cards, folder rows → glass.
- `CppNativeEngineCard` — metric tiles, parity receipt, build-pipeline rows.
- `CreateRealityModal` — opaque `#0a101d` → frosted `rgba(10,16,29,0.55)` +
  `blur(3xl) saturate(150)`.
- Header + tab bars — `slate-950/80` strips → whisper-white `bg-white/4`.

## Verification (visual + computed, not just types)

  remain**.
- **All four tabs cycled** (Command Matrix, Realities Grid, Deep Hierarchy,

- **Screenshots at 1440×900**: the nebula field and starfield visibly glow

## Design law going forward

Surfaces earn depth through **translucency + blur + hairline light**, never
through opaque dark fills. If a pane can't show the universe through it, it
isn't finished.
