## 2. Fixed — crashes & silent data loss (wave 1, `d1b35c8`)

| # | Issue | Evidence | Fix |
|---|---|---|---|
| 1 | Port 3000 busy → cryptic unhandled-rejection crash | `server/index.ts:315` | `server.on('error')` prints a plain-language "port busy" message + `startServer().catch()`. **Verified live** during this round's server restart. |
| 2 | Renaming a reality to a name containing `\` corrupted the generated module → eager glob white-screens the whole app | `server/realityDaemon.ts:388` | Name is now written with `JSON.stringify` via a function replacement (also immune to `$&` sequences); patches both `index.ts` and `surface.ts`. |
| 3 | `id`/`colorA`/`colorB`/`starColor` interpolated raw into generated TS — a crafted value could inject code; a weird value could white-screen the app | `server/realityTemplates.ts:37-42` | All interpolations go through the file's existing `esc()` helper. |
| 4 | Folder names with `-`/`.` (allowed by `sanitizeFolderName`) produced invalid exported identifiers (`my-realitySurface`) → invalid TS → white screen | `realityTemplates.ts` var-name functions | New `ident()` folds every non-identifier character to `_`. |
| 5 | Planet name spliced into `innerHTML` in diary export — markup in a name (e.g. from an imported shared backup) executed in the exporter's browser | `src/ui/exportDiary.ts:190` | Dynamic text now set via `textContent` (React-rendered paths were already safe). |
| 6 | Storage-full quota errors silently swallowed → user keeps typing, data gone on reload | `src/state.ts:286` | Quota failure now raises a throttled (1/min) warning toast: "storage is full — recent edits are NOT saved to disk." |
| 7 | ISO import buffered the entire disc image into RAM (multi-GB ISO → tab OOM crash) | `src/backend/executors/isoExecutor.ts:206` | Parser reads only a 64 MB directory-table window (`readDirectoryEntries` gained a `baseOffset` for windowed slices). |
| 8 | No import size ceiling — 2 GB+ uploads crashed the tab inside `encryptPayload` | `src/ui/VaultUI.tsx:4129` | Hard 2 GB cap with a clear skip toast + a heads-up toast past 512 MB. |

## 6. Known limits (documented, intentionally not fixed this round)

- The `kamuiPulse` script intentionally reuses the web-stage vortex uniforms; fired from the
  multiverse stage the tunnel + FOV still play but the web-bend is not drawn (the multiverse
  backdrop has no vortex hook). Visually still coherent.
- Exoplanet plates are subtle deep-field decoration by design (sizes 6.4k–10.4k at ~135k–178k
  units out) — they read as distant worlds in the deep field, not hero objects.
- ISO listing uses a 64 MB directory window; ISOs with directory trees larger than that
  (pathological) would list partially.
- Imported universe backups still allow arbitrary body *names* (rendering is safe everywhere
  now that the last `innerHTML` sink is gone; names are not sanitized at rest by design).
