# Round 10 — The Physics Becomes Visible (2026-09-24)

> "Every planet spins the same direction… every planet rotates around the same
> plane… the project has code that says gravity but shows no effect."

This wave makes the existing physics layer **visible on screen**. Nothing here is
random anymore — every motion traces a real law.

## Wave 1 — True 3D Kepler Orbits (`physicsEngine.ts`)

`calculateKeplerPosition` previously faked inclination with a flat vertical
wobble (`y = sin(nu + phase) * r * incl`) — every world rode the same apparent
sheet. Replaced with a real plane rotation about the node line:

```
zPlane = sin(nu) * r
y      = zPlane * sin(incl)
z      = zPlane * cos(incl)
```

Every world now crosses the ecliptic at its own ascending/descending nodes.
Orbit lines are sampled from the same function, so they render as inclined
ellipses automatically.

## Wave 2 — Real Orbital Inclinations (`seeds.ts`)

Seed values are actual solar-system analogues (degrees → radians inline):

| body | incl | analogue |
|---|---|---|
| cinder | 7.0° | Mercury |
| veil | 3.4° | Venus |
| aurelia | 0° | invariable-plane reference (Earth) |
| rust | 1.85° | Mars |

**Migration caveat:** stored user states keep old incl numbers — the old wobble
values (0..0.3) reinterpreted as radians are ≤ 17°, so old universes still show
varied planes, just not the exact analogue values. Fresh universes get the real
data. The Round-9 memoization signature includes `incl`, so changed orbits
re-solve automatically.

## Wave 3 — Axial Obliquity + Law-Based Retrograde Spin (`physicsEngine.ts`, `engine.ts`)

- `BODY_PROFILES` gained `tiltDeg?` with measured obliquities: anchor 7.25,
  cinder 0.03, **veil 177.4 (Venus — spins backwards)**, aurelia 23.44,
  rust 25.19, goliath 3.13, **mirror 97.77 (Uranus — rolls on its side)**,
  **hollow 122.5 (Pluto — retrograde)**, wisp 12.0, eventide 30.0.
- Generated/custom bodies fall back to a seeded spread (8°–63°) so no two
  worlds share an axis.
- **Engine spin was cosmetic random before** (`hash(3, id.length) > 0.82`).
  Now: `retrograde = axialTiltDeg > 90 ? -1 : 1` — spin direction is a
  consequence of obliquity, exactly the real rule (a world knocked past 90°
  spins retrograde relative to its orbit). Applied at both the home-body and
  inner-system body construction sites.
- Tilt groups use `rotation.order = 'YXZ'` with a per-body node rotation on Y
  plus the obliquity on Z, so axes lean in different compass directions.

## Wave 4 — The Ring-Plane Law (`engine.ts`)

Rings form in the equatorial plane of their world, so ring meshes are now
parented to the **tilted spin group** (both sites) instead of the untilted body
group. Goliath's rings (and any generated ringed world) now obey their planet's
obliquity — Mirror-style worlds would carry near-vertical rings.

## Wave 5 — Every Moon Rides Its Own Plane (`engine.ts`)

Moon records gained `incl` (seeded 0.18–0.48 rad ≈ 10°–27°) at all three
creation sites (inner-system giant court, home syncMoons, inner entry moons).
The two per-frame moon update sites now project moon position onto each moon's
own inclined plane — no more shared moon-sheet.

## Wave 6 — Gravity Made Visible: Barycentric Star Wobble (`engine.ts`)

The anchor star now physically responds to its worlds — the real
radial-velocity method used to detect exoplanets. Each frame the star's
position is the sum over every major world of

```
amp = min(0.22, 0.028 * (mEarth / aAU))     // mEarth ∝ radius³
x += cos(ang) * amp
y += sin(ang) * amp * sin(incl)
z += sin(ang) * amp * cos(incl)
ang = goldenOffset + simDays * orbitSpeed
```

Planets, dwarfs **and the vault black hole** all tug. Each tug advances at that
world's own orbital rate, so the drift is quasi-periodic, not a loop. Suppressed
during core mode and portal grabs. Aurelia's tug ≈ 0.028 units —
visible up close, never seasick.

## Wave 7 — Eventide, the Captured World (`seeds.ts`)

Eventide's orbit speed flipped to `−TAU / 12000`: negative mean motion. It is
now the system's only **retrograde orbiter**, consistent with its −12°
inclination and its lore (a quiet black hole that arrived from elsewhere).
Kepler math, memoized telemetry and the engine all handle the negative rate.

## Wave 8 — Native Kepler Parity (`cosmos_engine.cpp`, `cpp_bridge.ts`)

The C++/WASM accelerator and the bridge's TS fallback still carried the **old
flat wobble** — with the accelerator active, native frames would have fought
true-3D TS frames every other frame. Both ports now match
`calculateKeplerPosition` exactly (zPlane rotation about the node line).
