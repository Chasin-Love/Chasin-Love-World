> Strike order after the competitive research: sentiment aurora + cosmic echo +
> constellation search — three shallow dips into systems we already own, with
> the deepest emotional payoff per line of code. Everything here is offline,
> on-device, and derived only from the ACTIVE reality's diary.

BUILD: **R33**. Typecheck clean, production build green, every chain probed live.

## 1. The Sentiment Aurora — the star wears your mood

`src/sentiment/sentiment.ts` — a signal processor over the active reality's
entries:

- **Recency-weighted mood spectrum** — every entry lends its mood color with a
  14-day exponential half-life; two weeks of feeling dominate the light.
  Untagged entries still count as calm at half weight.
- **Intensity** — bright/burning entries read loud, calm reads quiet; the star
  never goes fully emotionally dark (floor 0.18).
- **Storm** — burning/heavy moods tear the band apart (turbulence drives real
  shader distortion).
- Palette mirrors MEANINGS colors so a page's meaning chip and the light it
  lends the star always agree.

`src/engine/shaders.ts` — the corona fragment gains `uAuroraA/B` (the two
strongest mood colors), `uAuroraMaskA/B` (which mood flows through each ray),
`uAuroraIntensity`, `uAuroraStorm`, `uEchoBloom`. Rays carry mood colors in a
latitude band like a real auroral oval; storm turbulence tears it with fbm noise.

Engine `setSentimentAurora()` **damps** toward the target (exponential smoothing)
— moods don't snap, they weather. App re-derives the signal only when the diary
JSON signature changes (immune to the 3s disk-sync heartbeats).

## 2. The Cosmic Echo — memories fall as golden meteors

On this calendar day in any earlier year, your pages return. The engine holds an
8-meteor pool of slow, golden, low meteors (220–520 units — the intimate shell,
actually clickable). Each carries `entryId / planetId / title`.

- `armEchoShower()` is **idempotent** per day+membership signature — diary edits
  never restart the shower mid-flight.
- Hovering a meteor blooms it and raises the memory card (title + "click to
  reopen the page"); a `pick()` prefix `echo:` keeps it out of the planet
  namespace entirely.
- Clicking fires `onEchoOpen` → App pulses that planet's constellation, plays
  the memory chime, and opens the diary on the right world.
- One glass toast announces the shower the first time it arms each day
  (`EchoShowerToast`), auto-fading after 5.6s.
- The star itself blooms (`uEchoBloom`) while echoes fly.

## 3. Constellation Search — Ctrl+K reaches the sky

The Command Palette (Ctrl+K) gains two sections:

- **Memories** — full-text retrieval across the active reality's pages
  (title/body/tags, HTML-stripped), scored title-first then newest, with mood,
  world name, and date hints. Choosing one reopens the diary.
- **Constellation** — type a tag and if multiple worlds share it, one command
  lights them all: `pulseConstellation(ids)` raises each planet's atmosphere
  glow in a wave (exponentially-damped per-planet pulse), with a toast
  ("✦ N worlds answer in the sky").

## Notes & caveats

- RAF is frozen in the dev preview webview, so damping values read 0 there —
  the *targets* were verified instead, and damping math is `cur += (t-cur)*min(1,dt*k)`.
- Echoes read from the active reality's entries only — the dimensional barrier
  holds: Reality B's memories never fall in Reality A's sky.
- Moods without timestamps use `createdAt`; future work could use weather
  (rain → fainter aurora) as a second input channel.
